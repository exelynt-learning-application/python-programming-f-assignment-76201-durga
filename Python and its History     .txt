1. What is Python and its History?

What is Python?
Python is a high-level, interpreted, and general-purpose programming language. It is easy to learn because of its simple syntax and is widely used for web development, data science, artificial intelligence, machine learning, automation, and software development.

History of Python:
Python was created by Guido van Rossum and first released in 1991. It was designed to make programming simple, readable, and efficient. Today, Python is one of the most popular programming languages in the world and has a large developer community.
